ETR Reconciliation Demo

This tool reconciles an ETR report (expected transactions) against loan notice documents, using a facility-code mapping to join them. Each ETR row ends up Ready (a notice matches on both asset code and transaction type) or Pending (with a specific reason). Ready rows can then be marked Processed and assigned to team members.

Things to try

  • Open a row with “+” to see exactly why it was Ready or Pending.
  • Search, sort and filter by column on each tab.
  • Tick a Ready row to mark it Processed, then Undo it.
  • Download a CSV of the current view.
  • Open the Members tab and auto-assign work.

Rules it enforces

  • An asset-code match alone is never enough: the notice type must match too.
  • Duplicate or conflicting notices and mappings are held for review, not guessed.
  • Missing or invalid dates, identifiers and mappings are reported with a reason.

Privacy

  • Demo data is fictional and embedded in this page.
  • Files you upload stay in your browser; there is no server.
  • “Reset Demo” wipes everything this page stored locally.
